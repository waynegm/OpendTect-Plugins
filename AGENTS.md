# AGENTS.md

WMPlugins: C++ plugins for [OpendTect](https://www.opendtect.org) (2026) plus Python "external attribute" scripts. C++17. This repo is codegraph-indexed — use `codegraph_explore` before reading/editing code.

## Build (pixi is the frontend)

The project is built with [pixi](https://pixi.prefix.dev); cmake runs inside the pixi env. Dependencies and build steps live in `pixi.toml`.

- `OpendTect_DIR` in `pixi.toml` `[activation.env]` must point at a compatible OpendTect **2026 installation** (currently `/opt/seismic/OpendTect_rc/2026`). Builds link against its prebuilt libs and CMake modules. If it's wrong, nothing builds.
- Order matters: `pixi run config` first (also builds `externals/` via task dependency), then:
  - `pixi run build` — Release; installs to `inst/2026/`
  - `pixi run build-dev` — Debug
- `pixi run reconfigure` = clean + config. `pixi run release` = launch OpendTect with the built plugins (`OD_USER_PLUGIN_DIR=./inst/2026`).
- pixi.toml only targets `linux-64` and `win-64`; macOS is unsupported. External deps (nanoflann, geotiff, nlohmann_json, sqlite 3.51.1, eigen…) come from conda-forge via pixi.
- `build_pixi/`, `inst/`, `.pixi/` are gitignored build artifacts. `wmplugins_version.h` and `VERSION.txt` are generated by cmake — don't hand-edit.

## Repo layout

- `plugins/<Name>/` + `plugins/ui<Name>/` — each plugin is two modules: `<Name>` is the computation engine, `ui<Name>` the Qt UI. Both are listed in the `PLUGINS` list in the top-level `CMakeLists.txt`. A per-plugin `CMakeLists.txt` is minimal: `OD_MODULE_DEPS`, `OD_IS_PLUGIN yes`, `OD_MODULE_SOURCES`, `OD_INIT_MODULE()`.
  - Adding a plugin = create the two dirs (copy an existing pair as the template) and append both to the `PLUGINS` list.
- `plugins/wm_include/` — shared plugin headers (wmplugins.h, convexhull.h, nanoflann_extra.h…), included as a SYSTEM dir.
- `plugins/NoRelease/` — benchmark/skeleton attribute plugins, deliberately **not** in the build. Templates for new attribute plugins: `[ST|MT]_MAI_[SAO|MAO]`.
- `bin/python/wmpy/` — Python scripts (AVO, Filtering, Curvature, DipAndAzimuth, PyLops, etc.) run by the **ExternalAttrib** plugin. They `import wmpy.extattrib`/`wmpy.extlib` for I/O scaffolding and need `bin/python` on `PYTHONPATH`. Installed to `inst/2026/bin/python`. Licensing varies per folder — check the license header/folder LICENSE before copying scripts.

## Verification

No test suite, no linter, no CI. Correctness gate = successful `pixi run build` (watch for your `.alo` files / install output) and, for plugin behavior, `pixi run release`.
